🍎 打不开？看这里（3 步搞定）
⚠️ macOS 会拦截未签名 App，显示「移到废纸篓」是正常的，不是 App 有问题。按下面 3 步操作即可。
第 1 步 · 安装
下载 .dmg 文件 → 双击打开 → 把 To be done 拖到「应用程序」文件夹
第 2 步 · 右键打开（关键！）
打开「应用程序」→ 找到 To be done
按住 Control 键点击 App 图标（或用两根手指点触控板）→ 选「打开」
⚠️ 不能直接双击！双击会被拦
第 3 步 · 点「打开」确认
弹出提示框 → 点「打开」→ ✅ 搞定！
以后双击就能打开，只需操作一次
还是不行？最后一招
打开「终端」App（在启动台搜「终端」），复制下面这行粘贴进去，回车，输入 Mac 密码：
xattr -cr "/Applications/To be done.app" && open "/Applications/To be done.app"
